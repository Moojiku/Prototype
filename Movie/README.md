# KapanLagi Movie Intelligence & Entity Integration — Prototype

**Status:** Interactive prototype for internal evaluation only. This is not a KLY production implementation. Movie records, editorial content, recommendation priorities, associations, schedules, and metrics are simulated demo data.

## Open the prototype

Open `index.html` through the repository's static site host (for example GitHub Pages). The page loads the compressed standalone prototype from the `payload/` chunks and expands it in the browser. Use a modern Chrome or Edge browser with `DecompressionStream` support.

If GitHub Pages is enabled for this repository, the folder URL is expected to be:

`https://moojiku.github.io/Prototype/Movie/`

The GitHub repository file view is available at:

`https://github.com/Moojiku/Prototype/tree/main/Movie`

## Scope and limitations

- All data and actions are simulated in the browser; no live CMS, API, database, GA4, or publishing connection exists.
- Existing CMS screens are prototype reconstructions based on supplied reference observations, not copied production source.
- No login or credentialed CMS access is required.
- Browser storage may retain demo edits in the current browser; use **Reset Demo** to restore the initial state.

The original editable source project and QA notes are maintained in the accompanying prototype ZIP package.
